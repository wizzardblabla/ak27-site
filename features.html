Ak27 2.0.0

Every feature, in one place.

Ak27 is a launcher and an in-game client in one 10 MB file. Everything is visual or quality-of-life: nothing gives you an unfair advantage.

⬢

Launching Minecraft

Every version, every loader, set up for you.

  • Every versionFrom 1.8.9 to 26.x (Java Edition), snapshots included.
  • 4 loadersVanilla, Fabric, Forge and NeoForge, installed automatically.
  • InstancesAs many as you want, each with its own version, mods, worlds, RAM, window size and Java options.
  • Automatic JavaThe right Java for each Minecraft version (8, 21, 25), downloaded for you.
  • Lighter on RAMSince 2.0.0 the game frees up to 3 GB of RAM at launch. A Max profile keeps everything reserved.
  • Optimization packWell-known performance mods (Sodium, Lithium...) in one click on Fabric and NeoForge.
  • Repair and logsRe-check game files, open the instance folder, read the game log.
◉

Account and content

Official sign-in and a built-in catalogue.

  • Official Microsoft sign-inMicrosoft's own page opens. Ak27 never sees your password. Several accounts supported.
  • Official demoNo Minecraft? Your Microsoft account launches the official demo with the full HUD and cosmetics.
  • Modrinth catalogueSearch and install mods, shaders, resource packs and modpacks, with dependencies.
  • Mods on and offDisable a mod without deleting it, or import your own files.

Game menus

New in 2.0.0: Minecraft's menus, the Ak27 way.

  • Ak27 title menuReplaces the Minecraft title screen in every version and loader: logo, player card, Singleplayer, Multiplayer, Mods, Settings.
  • Ak27 pause menuPress Esc in game: Resume, Settings, Ak27 Menu, Disconnect, with the server address.
  • In-game Ak27 menuRight Shift opens every launcher page right in the game, with a brand new animated design.
  • Custom iconsPick an icon for every tab and category from 120+ icons, in any color, or use your own image.
  • Menu backgroundsNebula, any live background, or your own pictures behind your menus.
  • HUD editorDrag every HUD element where you want it, then set its size, color and opacity.

What Ak27 will never do

On purpose.

  • No cheat modules: no KillAura, Aim Assist, Reach, hitboxes, ESP, Triggerbot or AutoClicker.
  • No cracked version: you need a Microsoft account, with the game or the official demo.
  • No "ping boost" and no connection tricks.

Known limits: on 1.13 to 1.14.3 the Ak27 menus and game-state features are not available. Ak27.exe is not digitally signed yet; the FAQ explains how to check your download.

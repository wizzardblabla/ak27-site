FAQ

Questions.

Is Ak27 a cheat client?

No. Every module is visual: HUD, cosmetics, skies and animations. There is no PvP module and nothing that gives you an advantage over other players.

Is my account safe?

Sign-in goes through Microsoft's official page. Ak27 never sees or stores your password.

Do I need to install mods?

No. The HUD and cosmetics load with the game on their own, so they work with Vanilla, Fabric, Forge and NeoForge without conflicts. You can still add mods from the catalogue.

Can other players see my cosmetics?

Cosmetics are drawn on your screen. Other Ak27 players see your Ak27 badge above your name.

Is Baritone allowed everywhere?

Baritone and Auto Build work in singleplayer and on servers allowed by the owner. Many servers forbid bots: check the rules before using them.

I don't own Minecraft. Can I try Ak27?

Yes. Sign in with any Microsoft account: if it doesn't own Minecraft Java, Ak27 starts the official Minecraft demo (singleplayer, about 100 minutes) with the full HUD and cosmetics. Buy the game or get PC Game Pass to play online.

Windows says Ak27 "might harm your PC". Is it safe?

Windows shows this warning for programs that are new and not yet downloaded by many people (SmartScreen). Ak27 is a small independent project and is not digitally signed yet, so Windows doesn't know it. Before running it, you can check that your file is the official one: open PowerShell in your Downloads folder and run Get-FileHash Ak27.exe. The result must match the SHA-256 shown on the release page. If it matches, click More info, then Run anyway. Never turn off your antivirus for Ak27, and only download it from this site.

Which systems are supported?

Windows 10 and Windows 11, 64-bit.
